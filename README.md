# Cindy Social Sync

Static website for the Cindy Social Sync TikTok developer app.

## GitHub Pages

Deploy this folder with GitHub Pages. The site uses relative links, so it works from either a user site or a project site.

After deployment, use these URLs in the TikTok developer form:

```text
https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY/terms.html
https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY/privacy.html
```

If this is deployed from a user site repository named `YOUR_GITHUB_USERNAME.github.io`, use:

```text
https://YOUR_GITHUB_USERNAME.github.io/terms.html
https://YOUR_GITHUB_USERNAME.github.io/privacy.html
```
